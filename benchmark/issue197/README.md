## 結論・計測結果

**3方式各200件を取得済み。3.8 Flashは保存済み3.7 / 3.6よりCERが低いが、応答は遅い。** ひらがなではCER 1.57%・完全一致87%、全件平均2.11秒。軽快さ重視なら3.6、今回のGemini比較で精度重視なら3.8が候補になる。推論設定・計測日時が異なるため、世代差だけに帰属する厳密な比較ではない。

ユーザーのシェルで2026-10-31 **16:28:53〜16:50:51（日本時間）** に計測した。各200件とウォームアップ6回の計606回、HTTP・タイムアウト等のリクエストエラーは0。終了理由は604回が `stop`、2回が `content_filter: OTHER`。キーは共有・記録していない。

## ブロック件数の訂正

初回ランナーは終了理由が `content_filter` と完全一致する場合だけブロックと判定していた。実測では `content_filter: OTHER` が返り、画面と元の監査JSONでは誤って `blocked=0` となった。終了理由から再集計すると **ローマ字入力の69番・174番の2件** が正しい。両件は空出力として既にCER 1に算入されているため、品質数値の取り直しは不要。

元の監査JSONは書き換えず保存し、訂正値を `summary.json` の `blocked_calls_recomputed` と `blocked_positions` に記録した。ランナーの判定も修正し、接尾辞付き終了理由の回帰テストを追加した。追加のAPI呼び出しは行っていない。

## 目的

既存のAJIMEE-Bench JWTD_v2/v1の同じ200例を、ローマ字・ひらがな・カタカナで評価し、保存済みGemini 3.7 Flash / 3.6 FlashとCER・完全一致率・応答時間・費用を比較する。

## 費用

2026-12-31までのStandard有料枠は、100万トークン当たり入力$0.75・出力$3.75（思考トークンを含む）、キャッシュ入力$0.075。固定入力500・出力200トークンと仮定すると、1回$0.001125、全件とウォームアップ606回で$0.68175、疎通9回で$0.010125。ただしlow推論分や実使用量で変動するため上限ではない。

ランナーの費用は返却された互換APIの `usage` に基づく有料枠換算の参考値。`completion_tokens` をそのまま使用し、内訳のreasoning_tokensを再加算しない。思考分の含まれ方は疎通結果でも確認する。無料枠・割引・税・使用量不明分・実際の請求額とは区別する。2027年以降は価格の再確認が必要なため、ランナーは停止する。

### 今回の返却使用量と留意点

606回の合計は入力233,664、返却出力9,241、返却総数246,104トークン。画面表示の **$0.20990175** は入力と返却出力だけの参考計算。疎通9回の$0.00349650を加えると **$0.21339825**。

ただし、31回で `total_tokens - prompt_tokens - completion_tokens` が正となり、合計 **3,199トークン** の内訳が不明だった。`completion_tokens_details` と `prompt_tokens_details` は全件nullで、思考分・キャッシュ分の詳細は取得できていない。**思考トークン0や、表示金額が請求総額であるとは断定しない。**

Googleの [トークン説明](https://ai.google.dev/gemini-api/docs/generate-content/tokens) では思考トークンも出力料金に含まれる。互換APIの差分すべてを課金出力と仮定して加算すると、本計測は **$0.221898** になる。ただしこの差分を思考トークンと断定するものでも、請求の上限を保証するものでもない。必要ならAI Studioの使用量・請求明細で照合する。元データと仮定による計算は区別して保存した。
