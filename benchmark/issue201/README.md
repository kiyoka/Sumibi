## 目的

低遅延・低コストな日本語変換モデルとしての適性を、保存済みGemini 3.6 / 3.8 Flashと比較する。3.1 Flash-Liteはpreview版の保存結果のみを参考比較に使い、正式版の測定とは扱わない。

AJIMEE-Bench JWTD_v2/v1の既存200例・同じプロンプトを使用し、ローマ字・ひらがな・カタカナを各200件計測する。各方式でウォームアップ2回を行うため、全件は606リクエスト。先に各方式1件の疎通確認（計9回）を行う。
